reference. It is included for use with the addon. The MIT statement above
describes the original code and documentation; it does not assert ownership

The addon obtains spell and item icons from the running game's APIs. It does
not bundle extracted game/client code or a collection of game spell icons.
Repository preview PNGs use sample data and reference icons for illustration;
they are offline layout previews, not native game screenshots. Preview PNGs
are not shipped inside the installable addon ZIP.
