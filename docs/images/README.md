# Project images

- **ReRollPreview.png** is a live in-game capture from Grimfall supplied by Vash.
  It is used as the main project screenshot and is published unchanged from the
  supplied PNG. It shows both history panels and both Hide Locked filters enabled.
- **titan-reliquary-preview.png** and **hide-locked-preview.png** are older
  offline layout previews with sample data. They are retained for reference,
  but are no longer displayed in the main README.

None of these documentation images are included in the installable addon ZIP.
The original release's notes about offline preview PNGs refer to the two older
preview files, not the subsequently supplied live screenshot.
