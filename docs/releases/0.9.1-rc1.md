## RE: Roller by Vash - first public release candidate

An ability and talent reroll planner for **Grimfall's custom WoW 3.3.5a client**,
with the gold-and-stone Titan Reliquary interface.

### Highlights

- Side-by-side Abilities and Talents with independent reroll buttons and scroll budgets.
- Protection locks saved per character and specialization slot.
- New **Hide Locked** switches for each column, with remembered settings and search support.
- Scrollable Ability History / Talent History panels with From/To tooltips.
- Current specialization name/icon, optional Quick Animation, Pause/Resume and Stop.
- Movable launcher, resizable planner, and bounded recent roll announcements.

### Download and install

Download **RE-Roller-0.9.1-rc1.zip** from the assets below, not the automatic
Source code archives. With WoW closed, extract its **GrimfallReroll** folder
into `Interface/AddOns`. The final file path should be
`Interface/AddOns/GrimfallReroll/GrimfallReroll.toc`.

Enable **RE: Roller by Vash**, then open it with `/rr` or the dice launcher.
When updating, preserve your `WTF` folder and saved variables. Do not rename
the addon folder.

### Requirements and limits

- Grimfall-specific APIs are required; this is not a generic WotLK/Classic/Retail addon.
- Abilities use Scroll of Destiny (640); talents use Scroll of Reshaping (639).
- Emblem is optional and is not bundled. PT Sans is included as a fallback.
- Offline tests use mocked APIs and do not replace live Grimfall testing.
- This is intentionally labeled a release candidate.

The public package preserves the existing 0.9.1-rc1 runtime files and adds
MIT/third-party notices. Checksums and a per-file manifest are included as
separate download assets. They are integrity aids, not a DRM or activation system.
